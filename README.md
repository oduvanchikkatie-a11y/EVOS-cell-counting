# EVOS-cell-counting
Here is an application for cell counting on processed PNG images and saving results for each image in CSV format

Using instruction:
1. Process images in ImageJ (browser version is available by link: https://ij.imjoy.io/). Final images must be binary
(red-black, green-black or combined images)
   Here is an example of raw and processed image:

2. Replace all processed images to single folder.
  
3. Run the program "EVOS_cell_counting"
   
   3.1 Enter the folder path WITHOUT apostrophe (' or ")
   
   3.2 Enter name of csv file that will be created. Extension CSV will be added automatically.

4. Enjoy!
